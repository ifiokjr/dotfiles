# GitHub Actions Conventions

## Naming Rules

- Workflow `name` values are lowercase.
- Job names are lowercase and do not use emoji prefixes.
- Step names are lowercase and include an action emoji prefix.
- Every step has an explicit `name`.

## Step Emoji Mapping

- `📥` checkout
- `🔧` install tools / Nix
- `📦` install dependencies
- `🧪` tests
- `🔍` lint/check
- `🎨` format
- `📝` generate files
- `🏗️` build
- `🤖` AI/automation
- `✅` verify/validate
