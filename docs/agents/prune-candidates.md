# Prune Candidates

## Redundant With Agent Baseline

- Long, generic explanations of what hooks or symlinks are.
- Generic commit-writing advice like “explain the why” (already baseline best practice).

## Too Vague To Be Actionable

- “Nix-first philosophy with reproducible environments” without a concrete rule.
- “Modular configuration groups” without an operational instruction.

## Overly Obvious

- “Changes are reflected instantly (same file via symlink)” repeated in multiple sections.
- Repeated reminders to run `tuckr status` after setup in multiple places.
